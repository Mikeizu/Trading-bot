# Gap analysis

The current goal is a broad, transparent technical-strategy research terminal with retained safety controls. Public descriptions of another app are not a substitute for its undisclosed algorithms, independent market evidence or broker authorization.

| Area | Current approach | Risk or missing evidence | Required next step |
|---|---|---|---|
| Strategy breadth | Explicit catalog across several technical families; bounded parameters and warm-up metadata | More candidates increase multiple-testing and selection bias | Predeclare hypotheses, use fresh chronological holdouts, evaluate stability and market coverage |
| Accuracy | Net metrics, sample counts, uncertainty, walk-forward and cost stress | No demonstrated calibrated prediction accuracy or durable edge | Independent data, forward observation and documented failure thresholds |
| Product-reference parity | Exact Google Play reference identified; access blocked | Listing/features/proprietary algorithms unverified | Read authorized public material when reachable; never claim inferred rules are copies |
| Data | Validated OHLC, explicit synthetic/CSV/broker source labels | No authentic historical bid/ask, payouts, financing or volume feed | Obtain licensed data and model only fields actually supplied |
| Research realism | Causal next-open fixed-expiry model, costs and isolated capital | No full tick/latency/liquidity/partial-fill execution model | Product-specific event-driven validation with authentic broker evidence |
| Strategy selection | Training-only weighted comparison and no-validated result | Sample scarcity and reuse of the same holdout | Fresh unseen data; parameter-stability and multiple-comparison studies |
| Regime/news | Heuristic price classification and calendar fail-safe | No calibrated regime model or licensed automatic event provider | Validate thresholds historically and integrate an authorized feed |
| Risk and recovery | Persistent loss, drawdown, exposure, cooldown, emergency and uncertainty gates | Complete external broker history is unavailable; unsigned local audit | Verified statements, restore drills and independently anchored records |
| Broker demo | Guarded official adapter and deterministic test doubles | Actual user permissions, WebSocket, purchase and settlement unverified | Separately authorized end-to-end demo acceptance run |
| Multi-market execution | Instruments only from broker metadata; no invented tradable symbols | Regional/product restrictions vary; CFD/MT5 absent | Separate official adapter, tick/lot/margin/financing and legal checks |
| User experience | Unified library, research, broker, journal and risk/health views | Full assistive-technology and international user testing incomplete | Accessibility review, localization and controlled user testing |
| Deployment | Source package and local launchers | No certified executable, remote auth, signed updates or hosted operations | Platform-specific validation and separate production-security design |

No gap is closed by increasing stake after losses, relaxing risk controls, inventing unavailable data, reporting simulated results as real, or promoting a candidate because it meets a win-rate target.
