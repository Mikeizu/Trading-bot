## Research-to-production evidence ladder

1. **Research:** deterministic rule and strategy version, documented costs, reproducible dataset. No orders.
2. **Historical validation:** adequate independent trade sample with after-cost expectancy and acceptable drawdown; not a win-rate target alone.
3. **Out-of-sample testing:** one predeclared untouched test interval; no fallback candidate selected on the same holdout.
4. **Walk-forward:** expanding chronological folds, purged overlap and embargo. Evaluate regime coverage and parameter stability before claiming robustness.
5. **Demo forward testing:** explicit authorization, fresh broker state, predefined observation period/sample, execution error/cost monitoring and separate demo records. This gate has not been executed in this environment.
6. **Optional live consideration:** separate code/security/legal/broker review and release. The current application has no live activation path.

Initial sample gates in code are research filters, not statistical proof. Sparse weekly/monthly signals may need years of data and observation. Repeated scans, multiple instruments or parameter variants increase false-discovery risk even when each report uses a holdout. Preserve versions and untouched data; do not re-optimize until a target win rate appears.

## Work that remains outside the current implementation

- Licensed, fresh economic-calendar ingestion and instrument relevance metadata.
- Official MT5 adapter with demo authorization, tick value, lot steps, margin/leverage, stops, financing, execution and reconciliation evidence.
- Authentic historical bid/ask, payouts, partial fills and execution-latency models.
- Parameter robustness and independent multi-market forward validation.
- OS-managed Windows credential persistence if desired; current memory-only tokens are intentional.
- Multi-user authentication/authorization, encrypted remote transport, deployment supervision, monitoring alerts, signed releases/updates and external audit checkpoints.
- Authorized broker-demo acceptance run and independent production security/legal review.
