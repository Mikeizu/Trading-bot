Calendar availability has not been checked.

Unavailable or stale event data blocks orders when calendar checks are required. A synthetic-market exception applies only when explicitly configured, never to forex by assumption.

Import a licensed economic-calendar snapshot

Choose a current JSON snapshot from a source you are permitted to use. The app validates timestamps and events; it does not fetch or invent economic news.

Required: source, updated_at, valid_until and events [{time, currencies:["USD"], impact:"high", before_minutes:30, after_minutes:30, name:"CPI"}]. Times use Unix UTC seconds. Maximum coverage: 7 days; snapshot freshness: 24 hours. No automatic provider sync.

Resume after an emergency stop

Resume only after investigating the cause. This clears the stop latch; it does not erase losses, release uncertain orders, or restart robots.
